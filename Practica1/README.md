# Práctica 1

## Objetivo

El objetivo de la práctica es preparar un entorno adecuado con las herramientas necesarias para realizar las prácticas del laboratorio. Especificamente instalar y configurar Haskell, su compilador (GHC) y el compilador interactivo (GHCi) para trabajar con el lenguaje, así como Git y GitHub para el control y gestión de los proyectos.

## Tiempo requerido

1 hora y media aproximadamente (no hice todo seguido).

## Comentarios y problemas que ocurrieron durante la instalacion

No tuve ningun problema durante la instalación de las herramientas. Git ya se encontraba instalado en mi computadora, entonces omití esa parte de la práctica. Después de instalar Haskell no fue necesario agregar GHCup al PATH manualmente con export PATH="$HOME/.ghcup/bin:$PATH", ya que el instalador preguntó directamente si se deseaba agregarlo al PATH y acepte esa opción.
